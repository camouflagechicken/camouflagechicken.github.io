// about

I've been writing code since I was a kid, and I never stopped taking systems apart to see how they work. My instinct is to distill any system into a logical flow, then build it back into working software — full-stack apps shipped end to end, automated workflows, and simulations where changing one variable reveals how the whole thing behaves.

That drive now powers my AI work: offline LLM infrastructure, real-time voice agents, multi-agent systems, and autonomous trading — where I sweat the reliability details (low-latency concurrency, durable memory, deterministic risk) that make software real.

I treat AI as a collaborator, not a competitor.
